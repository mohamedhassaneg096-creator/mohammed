# سجل التحديثات — AutoCut Changelog

## 1.3.0 (2026-11-25)
- دعم تثبيت التطبيق على الجهاز (Installable PWA): ملف manifest، Service Worker للتخزين المحلي، أيقونات كاملة، وزر «تثبيت التطبيق» في الشريط العلوي، مع الحفظ التلقائي الفوري عبر IndexedDB.
- التنفيذ على مرحلتين + قص الصوت الفوري: قص الصوت مباشرة في المرحلة 1 إلى مقاطع مرقمة مع تايم لاين صوتي بأسلوب CapCut، ثم تركيب وتصدير كل مشهد بشكل مستقل في المرحلة 2.
- معالجة خفيفة للفيديوهات الطويلة (45–60 دقيقة): وضع استهلاك «خفيف» افتراضي (تحديد خيوط FFmpeg والعامل الواحد وفواصل تبريد)، مع مستويات «خفيف / متوسط / سريع» وزر «إيقاف مؤقت / استئناف» وعداد الوقت المتبقي.
- تحسين استوديو الحركات: معاينة حية فورية للحركة (3–4 ثوانٍ) فور النقر على «تحريك المشهد»، ميزة «حركة خاطفة» (Snap Zoom) المدمجة في المعاينة وفي FFmpeg، وإلغاء الإجبار على ترتيب المشاهد مع التمرير التلقائي للشريط السفلي.

## 1.2.0 (2026-11-22)
- التفريغ أصبح عبر الاستيراد فقط (من Vibe أو أي برنامج تفريغ آخر بصيغ JSON وSRT وVTT) — تم إزالة محرك Whisper المدمج وحزمه الثقيلة لتثبيت أسرع وتقليل الحجم.
- شاشة «التفريغ (استيراد)» الجديدة: كشف تلقائي للصيغة ومستوى الدقة (كلمات أو جمل)، فحص الأخطاء الصارم، كاشف السطور المشبوهة (التكرار، بعد نهاية الصوت، اللغة المختلفة، المدة الصفرية) مع زر «تجاهل هذا السطر»، وتوزيع زمني ذكي للكلمات مع شارة «تقدير».
- شاشة «مشروع جديد» المحدّثة ببطاقات 2×2، واستيراد «مشروع سريع من فولدر» بنقرة واحدة، وزر «مشروع تجريبي»، وعارض موجة الصوت (Waveform) التفاعلي، واقتراح ملفات التفريغ والنص بنفس اسم الصوت.
- إضافة 3 ثيمات ألوان مريحة («ليل أزرق» الافتراضي، «غابة هادية»، «نهار») بتباين WCAG AA مع بقاء نقطة الحركة زرقاء دائماً.

## 1.1.0 (2026-11-22)
- إضافة نظام التحديثات السريعة (Delta Patch) من GitHub: تنزيل الملفات المتغيرة فقط بمقارنة Git SHA-1.
- إعدادات مصدر التحديث (المستودع، الفرع، المجلد الفرعي التلقائي، ورمز الوصول المخفي للمستودعات الخاصة) مع زر «اختبار الاتصال».
- فحص التحديثات التلقائي عند التشغيل مع شارة «تحديث متاح» دون تنزيل تلقائي.
- تحديث آمن على مراحل (staging، نسخ احتياطي لآخر 5 إصدارات، استبدال عبر عملية منفصلة، تثبيت تغييرات requirements فقط، ترقية بيانات المشاريع، واختبار ذاتي مع تراجع تلقائي عند الفشل).
- دعم التحديث المحلي من ملف ZIP أو مجلد كخيار بديل أوفلاين، وزر «التراجع للإصدار السابق»، ونسخ تقرير المشكلة مع حجب أي رموز سرية.

## 1.0.0 (2026-11-22)
- الإصدار الأول: التفريغ الصوتي المحلي عبر faster-whisper، المطابقة العربية، الخط الزمني المتصل، استوديو الحركات بالنقطة الزرقاء، التصدير المتوازي مع الذاكرة المؤقتة، والمراجعة اليدوية بعد التصدير.
